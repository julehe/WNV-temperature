# WNV-temperature
Code and Data supporting our study: "Disclosing temperature sensitivity of West Nile virus transmission: novel computational approaches to mosquito-pathogen trait responses"

A preprint version of our article is available on Biorxiv: https://www.biorxiv.org/content/10.1101/2024.09.16.613097v1

Fitted models are available from Figshare: https://figshare.com/articles/dataset/Bayesian_hierarchical_model_fits_for_the_manuscript_Uncovering_temperature_sensitivity_of_West_Nile_virus_transmission_novel_computational_approaches_to_mosquito-pathogen_trait_responses_/28387862?file=52260494
